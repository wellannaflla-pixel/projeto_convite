# 📝 RSVP App - Confirmação de Presença

Este é um projeto **Full Stack** simples desenvolvido em **Python** com o framework **Flask**. A aplicação permite que convidados confirmem sua presença em um evento, informando o nome e a quantidade de acompanhantes.

## 🚀 Funcionalidades
- Formulário de confirmação de presença.
- Armazenamento de dados em banco de dados local (SQLite).
- Painel Administrativo para visualização da lista de confirmados e soma total de pessoas.

## 🛠️ Tecnologias Utilizadas
- **Backend:** Python + Flask
- **Banco de Dados:** Flask-SQLAlchemy (SQLite)
- **Frontend:** HTML5 e CSS3

## 📋 Como executar o projeto
1. Clone este repositório.
2. Crie um ambiente virtual: `python -m venv venv`.
3. Ative o ambiente: `.\venv\Scripts\activate` (Windows).
4. Instale as dependências: `pip install flask flask-sqlalchemy`.
5. Execute a aplicação: `python app.py`.
6. Acesse `http://127.0.0.1:5000` no seu navegador.
